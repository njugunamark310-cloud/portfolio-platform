A single-page portfolio application built with React that allows users to view, search, and add projects.

Features

View existing projects.

Search and filter projects.

Add new projects through a form.

Display a message when no projects match the search.

Responsive design.

Technologies

React

JavaScript

Vite

CSS Modules

Vitest

React Testing Library

Installation

npm install
npm run dev

Running Tests

npx vitest run
